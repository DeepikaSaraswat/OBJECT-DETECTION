# Object Detection using YOLO

## Overview

This project is based on Object Detection using the YOLO (You Only Look Once) algorithm with Python and OpenCV. The model is trained to detect multiple objects in images and videos using the COCO dataset.

## Features

* Real-time object detection
* Detection of multiple objects
* Bounding box visualization
* Fast and accurate predictions
* Uses YOLO and OpenCV libraries

## Technologies Used

* Python
* OpenCV
* YOLO
* NumPy

## Dataset

The project uses the COCO Names Dataset for object detection and classification.

## Project Functionality

The system processes images or video frames and identifies objects by drawing bounding boxes and labels around detected objects.

## How to Run

1. Clone the repository
2. Install required libraries:

```bash
pip install opencv-python numpy
```

3. Run the Python file:

```bash
python object_detection.py
```
